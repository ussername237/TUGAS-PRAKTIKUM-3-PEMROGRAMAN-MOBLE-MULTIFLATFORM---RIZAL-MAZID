# Diary App
Aplikasi Diary sederhana yang dibuat menggunakan React Native dan Expo. Aplikasi ini digunakan untuk mencatat kegiatan atau cerita sehari-hari.

## Fitur
- Menampilkan daftar diary
- Mencari catatan
- Menambahkan catatan baru
- Melihat detail catatan
- Tombol suka pada catatan

## Teknologi
- React Native
- Expo
- JavaScript
